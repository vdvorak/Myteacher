# Students and materials belong to the instance, not to a teacher

Teachers substitute for each other and share students, so a student account that lived inside one teacher's data would have to be duplicated or migrated on every substitution. We decided that student accounts belong to the instance and are enrolled into courses by teachers, and that courses can have more than one teacher. The exact sharing model between teachers is still being decided.

## Consequences

- A teacher never "owns" a student; access to a student's progress comes through the courses the teacher has access to.
- Deactivating a student is an instance-level action, not a per-course one.
